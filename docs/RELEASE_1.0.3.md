# 1.0.3 배포 기록

## 변경

- 팝업의 초기 로딩, 저장소 조회 실패 및 재시도 안내
- local 저장 데이터 변경 구독, 늦게 도착한 조회 응답 무시, 구독 해제
- 초기화 실패 안내, 수집 중 초기화 방지, 확인/복사 타이머 정리
- 한국어 문서 언어와 제목, 키보드 포커스, 스크린리더 상태 메시지
- 원티드의 페이지 번호와 실제 목록 변경을 함께 확인
- 첫 페이지 복귀 실패 시 오류 처리 및 기존 저장 데이터 유지
- 공개 소개 페이지의 사용법/FAQ/검색·공유 메타데이터, 웹스토어 설명 개선

권한, 저장 형식, 웹앱 전달 계약은 변경하지 않았다.

## 자동 검증

- `npm test`: 12개 파일, 78개 테스트 통과 (변경 전 63개)
- `npm run build`: TypeScript 검사, 프로덕션 번들 및 ZIP 생성 통과
- 최종 결과와 파일: `release/crx-jobdiary-extension-1.0.3.zip`
- 팝업 JS gzip 크기: 변경 전 63.15KB → 변경 후 약 63.61KB
- ZIP 확인: 91,281바이트, 26개 항목, 루트 manifest 버전 1.0.3
- `storage` 권한 유지, 프로덕션 웹앱 origin만 허용, 개발용 key/localhost 미포함
- 테스트 파일·소스맵·개인키 미포함, `git diff --check` 통과

## 실제 Chrome 확인 (미실행)

로그인한 지원현황 페이지 및 웹스토어 개발자 계정에 연결되지 않아 아래 항목은
자동 테스트로 대체했다고 간주하지 않는다.

1. `dist/`를 압축해제 확장으로 로드한 뒤 각 사이트 지원현황에서 수집한다.
2. 원티드 1페이지/중간 페이지 시작, 느린 페이지 전환, 마지막 페이지에서 건수와 경고를 확인한다.
3. 수집 중 팝업을 닫았다 다시 열고 저장 결과를 확인한다.
4. 전체 복사 후 스프레드시트에 붙여넣고 저장 내역이 유지되는지 확인한다.
5. 취준일기 열기로 웹앱 가져오기를 확인한다.
6. 키보드 포커스와 스크린리더 안내, 초기화 확인 동작을 확인한다.
7. 기존 웹스토어 스크린샷과 새 팝업의 문구가 일치하는지 확인한다.

## 제출 및 공개 페이지 반영 (미실행)

- 개발자 대시보드에서 기존 항목의 **패키지 → 새 패키지 업로드**로 ZIP을 올린다.
- `docs/STORE_LISTING.md`의 설명을 반영하고 심사를 제출한다.

- GitHub Pages/Jekyll 빌드와 배포 후 메타데이터·개인정보처리방침 링크 확인은 미실행이다.
- 이 기록은 업로드/심사 제출/공개 배포가 완료됐다는 의미가 아니다.
