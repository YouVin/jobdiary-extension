# 권한 사용 이유 (초안)

> ⚠️ 크롬 웹스토어 개발자 대시보드의 "개인정보처리(Privacy practices)" 탭에
> 그대로 붙여넣을 수 있게 준비한 초안이다. 대시보드 필드명은 구글이 UI를
> 바꾸면 조금씩 달라질 수 있으니, 실제 제출 시 항목명을 확인하며 맞는 칸에
> 넣을 것.

## 단일 목적 설명 (Single purpose description)

```
사람인, 잡코리아, 원티드 지원현황 페이지에서 유저가 지원한 내역(회사명,
공고명, 상태, 지원일)을 유저의 명시적인 버튼 클릭으로 수집해 브라우저
로컬에 저장하고, 유저가 원할 때 취준일기 웹앱으로 전달한다.
```

## 권한별 사용 이유 (Permission justification)

### `storage`

```
수집한 지원 내역을 유저의 브라우저 로컬 저장소(chrome.storage.local)에
저장하기 위해 필요합니다. 이 정보는 브라우저 밖으로 자동 전송되지 않으며,
유저가 팝업의 "초기화" 버튼을 누르거나 익스텐션을 삭제하면 함께 삭제됩니다.
```

### Host permission

실제 manifest 패턴(`manifest.config.ts`의 `host_permissions` 그대로):

```
https://*.saramin.co.kr/*
https://www.jobkorea.co.kr/*
https://jobkorea.co.kr/*
https://www.wanted.co.kr/*
https://wanted.co.kr/*
```

```
유저가 이미 로그인해서 보고 있는 사람인·잡코리아·원티드의 지원현황
페이지에서, 유저가 익스텐션 팝업의 "지원내역 수집하기" 버튼을 직접 눌렀을
때만 화면에 표시된 지원 내역(회사명, 공고명, 상태, 지원일 등)을 읽기 위해
필요합니다. 로그인 세션, 쿠키, 인증 토큰 등 계정 정보에는 접근하지 않습니다.

위 host_permissions는 크롬 권한 체계상 스킴+호스트 단위로 부여되어 각
사이트 오리진 전체를 포함하지만, 실제로 코드가 실행되고 데이터를 읽는
범위는 그보다 좁습니다 — 콘텐츠 스크립트는 각 사이트의 지원현황 페이지
경로에만 삽입됩니다(예: 사람인은
`/zf_user/persons/apply-status-list*`, content_scripts.matches 기준).
```

### Remote code

```
이 익스텐션은 원격 코드를 실행하지 않습니다. 모든 로직은 익스텐션 패키지에
포함된 코드로만 동작합니다.
```

## 데이터 사용 공개 (Data usage disclosure) — 체크리스트 참고 답변

대시보드의 데이터 수집/사용 관련 체크박스에 답할 때 참고할 내용:

| 질문 | 답변 | 비고 |
|------|------|------|
| 수집하는 데이터 유형 | Website content | 지원현황 페이지에 표시된 지원 내역 텍스트(회사명/공고명/상태/지원일). 계정 정보·비밀번호·결제 정보 등은 해당 없음 |
| 개인 식별 정보(PII) 수집 여부 | 아니오 | 유저 본인 계정에 로그인된 상태에서만 동작하지만, 유저의 이름·이메일·전화번호 등을 별도로 수집하지 않음 |
| 제3자에게 데이터 판매 여부 | 아니오 | 판매하지 않음 |
| 익스텐션 핵심 기능과 무관한 목적으로 사용 여부 | 아니오 | 수집한 데이터는 로컬 저장/클립보드 복사/취준일기 웹앱 전달에만 쓰임 |
| 신용도 평가·대출 심사 목적 사용 여부 | 아니오 | 해당 없음 |
