# 취준일기 익스텐션

사람인 · 잡코리아 · 원티드 지원 내역을 버튼 한 번으로 모아 [취준일기](https://github.com/YouVin/jobdiary) 웹앱으로 전달하는 크롬 확장 프로그램입니다.

이 사이트는 크롬 웹스토어 심사용으로 개인정보처리방침을 게시하기 위한 페이지입니다.
