# 취준일기 익스텐션

사람인 · 잡코리아 · 원티드의 지원현황을 모아 복사하거나 [취준일기 웹앱](https://jobdiary.vercel.app)으로 가져오는 크롬 확장 프로그램입니다.

[Chrome 웹스토어에서 설치하기](https://chromewebstore.google.com/detail/afnboeihbppogfinbickjaaadcgjkmil)

## 지원하는 기능

- 회사명, 공고명, 지원일, 지원 상태 수집
- 사이트별 지원 내역 저장 및 재수집 시 해당 사이트 내역 갱신
- 저장한 내역을 표로 복사해 스프레드시트 등에 붙여넣기
- 취준일기 웹앱으로 저장한 내역 가져오기

## 사용 방법

1. 지원 사이트에 직접 로그인하고 지원현황 페이지를 엽니다.
2. 확장 프로그램 아이콘을 누르고 **지원내역 수집하기**를 선택합니다.
3. 수집이 완료되면 건수와 안내 메시지를 확인합니다. 일부 수집 안내가 나오면 페이지를 확인하고 다시 시도합니다.
4. 다른 사이트에서도 반복한 뒤 **전체 복사** 또는 **취준일기 열기**를 선택합니다.

| 사이트 | 수집할 화면 |
| --- | --- |
| 사람인 | [입사지원현황](https://www.saramin.co.kr/zf_user/persons/apply-status-list) |
| 잡코리아 | [잡코리아](https://www.jobkorea.co.kr) 로그인 후 마이페이지의 입사지원현황 |
| 원티드 | [지원현황](https://www.wanted.co.kr/status/applications/applied) |

## 자주 묻는 질문

### 로그인 정보가 필요한가요?

확장 프로그램에 아이디나 비밀번호를 입력하지 않습니다. 사용자가 직접 로그인한 사이트의 지원현황을 수집하며, 로그인 정보와 인증 토큰을 수집하지 않습니다.

### 복사하면 저장한 내역이 사라지나요?

복사만으로는 삭제되지 않습니다. 같은 사이트를 다시 수집하면 그 사이트의 저장 내역을 교체하며, **초기화**를 확인하면 모든 사이트의 저장 내역을 삭제합니다.

### 내역을 찾지 못하거나 일부만 수집됐다고 나와요.

지원현황 목록이 표시되는지 확인한 뒤 다시 시도해 주세요. 필터, 페이지 로딩 지연, 사이트 구조 변경에 따라 수집 결과가 달라질 수 있습니다.
