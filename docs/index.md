# 취준일기 익스텐션

여러 채용 사이트에 남긴 지원 기록을 한곳에 모으세요.

> **1.1.0 기능 안내**입니다. 현재 소스와 운영 웹앱을 기준으로 하며, Chrome 웹스토어 심사·배포는 별도입니다. 설치한 버전에 따라 흑백 화면·마감일 보충·지원 이력 자동 표시의 사용 가능 여부가 다를 수 있습니다.

[Chrome 웹스토어](https://chromewebstore.google.com/detail/afnboeihbppogfinbickjaaadcgjkmil) · [취준일기 웹앱](https://jobdiary.vercel.app)

## 처음 사용하는 순서

1. 채용 사이트에 직접 로그인한 뒤 **지원현황 페이지**에서 익스텐션의 **지원내역 수집하기**를 누릅니다.
2. **취준일기로 가져오기**를 눌러 웹앱에 로그인하고 수집 내역을 저장합니다. 다른 사이트에서도 같은 순서로 반복할 수 있습니다.
3. 잡코리아·사람인 공고 화면을 열면 저장 이력과 같은 공고의 제목 옆에 **지원 이력 있음** 또는 **지원취소 이력**이 표시됩니다.

| 사이트 | 수집할 화면 | 공고 이력 자동 표시 |
| --- | --- | --- |
| 사람인 | [입사지원현황](https://www.saramin.co.kr/zf_user/persons/apply-status-list) | 지원 |
| 잡코리아 | 로그인 후 [입사지원현황](https://www.jobkorea.co.kr/User/ApplyMng) | 지원 |
| 원티드 | [지원현황](https://www.wanted.co.kr/status/applications/applied) | 현재 미지원 |

자동 표시는 정확한 공고 주소/ID를 확인할 수 있는 목록 링크와 단일 상세 제목이 대상입니다. 모든 페이지 구조·iframe 내부를 지원하는 것은 아닙니다. 원티드 지원현황에는 현재 비교에 필요한 공고 주소가 없어 표시 대상에서 제외합니다.

## 팝업에서 할 수 있는 일

- **전체 복사**: 모은 내역을 표로 복사합니다. 복사해도 저장 내역은 유지됩니다.
- **수집 내역 초기화**: 한 번 더 확인하면 세 사이트 수집 슬롯을 비웁니다. 웹앱 기록·표시용 비교 캐시는 지우지 않습니다.
- **지원 이력 설정**: 자동 표시를 끄거나 연결 상태를 확인합니다. 끄면 사이트의 배지도 제거됩니다.
- **이력 갱신**: 웹앱을 열어 저장 이력을 다시 조회합니다. 수집 내역을 다시 가져오는 동작과는 다릅니다.

## 자주 묻는 질문

### 라벨이 보이지 않아요.

먼저 수집한 내역을 웹앱으로 가져온 뒤 지원 이력 설정의 연결 상태를 확인하세요. 이미 웹앱에 저장돼 있다면 **이력 갱신**으로 최신 이력을 불러오세요. 공고 주소를 확인할 수 없는 기록은 비교에서 제외되며, 라벨이 없다는 이유만으로 미지원이라고 판단하지 않습니다.

### 채용 사이트에서 로그아웃했는데도 라벨이 보여요.

라벨은 **취준일기 웹앱 계정에 저장된 이력**을 기준으로 합니다. 사람인·잡코리아 로그인 상태와는 별개라 해당 사이트에서 로그아웃해도 남습니다. 취준일기 웹앱에서 로그아웃하면 이 브라우저의 해당 계정 비교 캐시와 배지를 정리합니다. 잠시 표시만 끄려면 팝업의 **자동 표시**를 끄세요.

### 마감된 공고나 불합격 이력도 표시하나요?

같은 공고에 지원한 사실은 남아 있으므로 표시합니다. 마감·불합격을 이유로 비교에서 제외하지 않고 지원취소는 따로 구분합니다.

### 다른 기기에서 바꾼 기록도 바로 반영되나요?

이 브라우저에서 웹앱을 열어 최신 이력을 불러와야 합니다. 웹앱을 닫은 동안 다른 기기의 변경을 즉시 알 수는 없습니다.

### 로그인 정보가 필요한가요?

익스텐션에 아이디·비밀번호를 입력하지 않습니다. 기존 로그인 상태의 지원현황을 사용자가 누를 때 읽습니다. 자동 표시는 웹앱에서 받은 사이트·공고 ID·지원/취소 등 최소 이력으로 브라우저 안에서 비교합니다.

### 마감일이 없는 내역은 왜 그런가요?

연도까지 정확하게 확인한 날짜만 보충합니다. 상시채용·출처 없음·조회 실패는 날짜를 비워 두고 지원내역은 저장합니다.
